# 中餐丙級術科練習系統 — 使用手冊

給練習中餐丙級證照術科考試的學員，從註冊帳號到寫筆記、上傳自己練習照片的完整操作說明。

## 一、開始使用

打開網站首頁，會看到「題組總覽」，列出所有題組（例如 301-1、301-2...），可以用上方搜尋框輸入題組編號或菜名快速篩選。點選任一張卡片，就會進入該題組的詳細頁面。

## 二、註冊帳號 / 登入

網站右上角有一個「登入」連結。

1. 點擊「登入」
2. 第一次使用的人，點畫面下方的「還沒有帳號？註冊一個」
3. 輸入想要的帳號、密碼，按「註冊」
4. 註冊完成後會自動登入，並回到你剛剛在看的頁面

之後要再次使用時，同樣點「登入」，輸入剛剛設定的帳號密碼即可，不用重新註冊。登入之後，右上角會顯示「學員：你的帳號名稱」，代表已經登入成功。

> 這個帳號只是用來同步你的個人筆記和練習照片，跟任何人都不共用，請自己保管好密碼。

## 三、題組詳細頁面

進入題組後，上方有三個分頁：

- **烹調指引**：每道菜的刀工、烹調法、主材料、材料組合、烹調步驟、調味規定等，也是寫筆記、上傳自己練習照片的地方
- **材料清點清單**：應檢材料的品名、規格、數量
- **刀工規格清單**：刀工規格明細，以及水花／盤飾的指定參考圖

## 四、我的筆記（登入後才會出現）

在「烹調指引」分頁，每一道菜下面都有一個「我的筆記」欄位（沒登入的話這個欄位不會顯示，先完成第二步的登入）。

- 直接在欄位裡輸入文字，例如這道菜的鹽/糖用量、火候、容易出錯的地方
- 打完字會自動儲存，欄位下方會顯示「儲存中...」→「已儲存」
- 筆記是跟著你的帳號走的，不是存在瀏覽器裡，所以換手機、換電腦，只要登入同一個帳號，筆記都看得到
- 每道菜的筆記是分開的，不會互相混在一起

## 五、上傳自己練習的照片／影片（登入後才能上傳）

同樣在「烹調指引」分頁，每道菜的「我的筆記」下面有一個「我的照片／影片」區塊。

1. 點「選擇檔案」，挑選你要上傳的照片或影片
2. 如果是照片，可以選分類：步驟照片 / 完成圖
3. 可以加一段文字說明（選填）
4. 點「上傳」，會看到上傳進度百分比

上傳後的照片/影片只有你自己登入時看得到，其他學員或訪客都看不到；如果要刪除，點照片右上角的「×」，會跳出確認視窗，確認後才會真的刪除，不會誤刪。


## 六、登出

右上角原本顯示「學員：你的帳號名稱」的地方，旁邊會有「登出」按鈕，點了就會登出，回到首頁。登出後「我的筆記」、「我的照片／影片」都會先隱藏起來，要看的話重新登入同一個帳號即可。

## 常見問題

**Q: 我可以用同一個帳號在不同裝置登入嗎？**
可以，筆記跟照片都是綁定帳號存在資料庫，不是存在裝置本機，所以換裝置登入同一帳號都看得到。

**Q: 忘記密碼怎麼辦？**
目前系統沒有忘記密碼的自助流程，需要請系統管理員協助處理。

**Q: 上傳照片/影片有格式限制嗎？**
照片支援 jpg / png / webp，影片支援 mp4 / mov。影片檔案大小上限視後端目前用哪個雲端儲存服務而定：用 AWS S3 到 500MB。手機拍的影片通常解析度較高、檔案較大，建議拍攝時選擇較低畫質，或用剪輯 App 壓縮後再上傳。
